# MECHANICA · Классикалық механика оқу атласы

Қазақ тіліндегі жеті беттік интерактивті сайт: классикалық механиканың негізгі есебі, тура және кері есептер, бастапқы шарттар және себептілік принципі. Материал БӨЖ презентациясының 1–20-слайдтарының тақырыбы мен құрылымына сүйенеді. Тұрақты қорытқы күш жағдайындағы теңдеулер бөлек қадамдармен шығарылады.

## Беттер

`index.html` — шолу және 3D көрініс; `theory.html` — негізгі ұғымдар мен Ньютон заңы; `direct.html` — параметрлері өзгеретін тура есеп және толық шығару; `inverse.html` — параболалық және шеңберлік қозғалыстың кері есебі; `initial.html` — бастапқы шарттарды салыстыру; `causality.html` — детерминизм және болжам; `conclusion.html` — қорытынды және өзіндік тексеру.

## Жергілікті іске қосу

Node.js 20.19+ немесе 22.12+ қажет.

```sh
npm ci
npm run dev
```

Ашу: `http://127.0.0.1:4174/`. Физикалық модель мен формулалар браузерде орындалады; келушіге тіркелу, серверлік есептеу немесе ақылы қызмет қажет емес.

## Тексеру

```sh
npm test
npm run build
```

Модель: `src/physics.js`. Сайт генераторы: `build-pages.mjs`. Парақтар мәтіні мен формулалары: `src/content.js`. 3D көрінісі: `src/scene.js`. Интерактив: `src/main.js`.

Тура есепте тұрақты масса мен күш, инерциялық санақ жүйесі қарастырылады. Жермен соқтығысу және ауа кедергісі модельденбейді. 3D векторлар көрнекілік үшін масштабталады; сандық мәндер SI бірліктерінде есептеледі.
